## Wanted source alignment

- The centralized color layer uses inspected Wanted primary, label, line, disable, negative, inverse, and static tokens.
- Dense 28-36 px editor controls preserve the inspected Wanted type rhythm, corner language, focus blue, hover/pressed overlays, and disabled treatment.
- App-specific Layers, Inspector, selection overlay, Debug panel, and status surfaces use the documented editor adaptations rather than an unrelated visual system.
- `lucide-react` 0.468 is used consistently under ISC. It is documented as an implementation icon dependency, not as an exported or byte-matched Wanted asset.
- No emoji, font icon, hand-authored mixed icon set, or Canvas2D fallback is present.

## Interaction and accessibility audit

- Semantic buttons, labelled numeric fields, tree/treeitem roles, selected/expanded state, dialog labelling, native checkbox/switch controls, and visible focus styling are present in product code.
- Actual DOM/CDP input verified selection, Shift multi-select, visibility/lock, move, resize, rotate, Inspector commit, Escape rollback, Undo/Redo, create, Group, nested child movement, Ungroup, pan, zoom-around-pointer, fit, Worker restart, and 10k/100k fixture actions.
- One persistent drag creates one history entry; Escape creates none.
- Camera operations preserve persistent revisions. Pan coalescing accumulates unsent deltas, preserving the final pointer intent.
